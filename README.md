# وارد 3.0 - نظام إدارة وتتبع المعاملات

## نظرة عامة
تطبيق **وارد 3.0** هو نظام متكامل لتتبع وإدارة دورة حياة المعاملات والخطابات الإدارية والحكومية، من الاستلام حتى الأرشفة النهائية.

## المميزات الرئيسية
- ✅ لوحة تحكم تفاعلية مع إحصائيات فورية
- ✅ دورة حياة كاملة للمعاملات (9 حالات)
- ✅ بحث متقدم وتصفية
- ✅ تقارير شاملة
- ✅ دعم متعدد اللغات (العربية/الإنجليزية)
- ✅ قاعدة بيانات محلية SQLite
- ✅ أمان عالي (PIN، بصمة)
- ✅ سجل تدقيق كامل

## التقنيات المستخدمة
- React Native (Expo)
- SQLite
- React Navigation
- i18next للترجمة

## الهيكل
```
/workspace
├── App.js                    # نقطة الدخول
├── app.json                  # إعدادات Expo
├── package.json              # التبعيات
├── src/
│   ├── screens/              # الشاشات
│   │   ├── DashboardScreen.js
│   │   ├── TransactionsScreen.js
│   │   ├── TransactionDetailScreen.js
│   │   └── ...
│   ├── components/           # المكونات
│   ├── navigation/           # التنقل
│   ├── services/             # الخدمات
│   │   └── database.js       # قاعدة البيانات
│   ├── models/               # النماذج
│   ├── utils/                # الدوال المساعدة
│   └── i18n/                 # الترجمة
```

## التثبيت والتشغيل
```bash
npm install
npm start
```
