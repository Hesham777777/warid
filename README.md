# نظام إدارة وتتبع المعاملات (وارد 3.0)

## نظرة عامة
تطبيق **وارد 3.0** هو نظام متكامل ومخصص لتتبع وإدارة دورة حياة المعاملات والخطابات الإدارية والحكومية، بدءاً من استلامها وتسجيلها، مرورا بالتوجيه والمتابعة، وحتى الإنجاز والأرشفة النهائية.

---

## دورة حياة المعاملة
تمر المعاملات داخل التطبيق بالحالات التالية:
1. **وصلت:** استلام المعاملة أولياً.
2. **قيد التسجيل:** إدخال البيانات والملفات الخاصة بالمعاملة.
3. **نشطة:** المعاملة جارية وتحت العمل.
4. **موجّهة:** إحالة المعاملة إلى جهة أو موظف مختص.
5. **حالات المتابعة:** (منتظرة رد / معلّقة / متأخرة).
6. **مكتملة:** إنجاز المطلوب بالكامل.
7. **مؤرشفة:** نقل المعاملة إلى الأرشيف النهائي.

---

## المميزات والخصائص الرئيسية
* **لوحة التحكم (Dashboard):** عرض إحصائيات فورية وتفاعلية عن حالة المعاملات وسير العمل.
* **محرك الإشعارات الذكي:** تنبيهات فورية بالمهل الزمنية، المواعيد النهائية، والمعاملات العاجلة والمتأخرة.
* **البحث والتقارير:** 
  * نظام بحث دقيق ومفلتر للوصول السريع لأي معاملة.
  * استخراج وتصدير تقارير إحصائية ورسمية متعددة الصيغ.
* **الأمان والحماية:**
  * تشفير البيانات الحساسة.
  * المصادقة عبر رقم PIN أو البصمة (Biometric Auth).
  * سلة محذوفات مع إمكانية استعادة البيانات خلال 30 يوماً.

## البنية التقنية (Tech Stack)
* **واجهة المستخدم (Frontend):** React Native (Expo)
* **لغة البرمجة:** JavaScript
* **قاعدة البيانات المحليّة:** SQLite
* **التنقل:** React Navigation
* **الترجمة:** i18next
* **المصادقة البيومترية:** expo-local-authentication
* **التخزين الآمن:** expo-secure-store

## التثبيت والتشغيل

### المتطلبات
- Node.js (v16 أو أحدث)
- npm أو yarn
- Expo CLI

### خطوات التثبيت

1. تثبيت التبعيات:
```bash
npm install
```

2. تشغيل التطبيق:
```bash
npm start
```

3. اختيار المنصة:
- اضغط `a` لتشغيل على Android
- اضغط `i` لتشغيل على iOS
- اضغط `w` لتشغيل على Web

## حالات المعاملة المتاحة
- `arrived` - وصلت
- `registering` - قيد التسجيل
- `active` - نشطة
- `directed` - موجّهة
- `pending` - منتظرة رد
- `suspended` - معلّقة
- `late` - متأخرة
- `completed` - مكتملة
- `archived` - مؤرشفة

## الأولويات
- `low` - عادي
- `medium` - متوسط
- `high` - عاجل
